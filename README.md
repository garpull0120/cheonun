홈페이지: https://cheonunaircon.co.kr (아임웹, 기본 주소 https://cheonun.imweb.me)

## 폴더 안내

| 위치 | 내용 |
|---|---|
| 맨 위 폴더 (`*.jpg`, `*.mp4`) | 홈페이지에 들어가는 사진·영상. jsDelivr로 불러옵니다 |
| `site/widgets/` | 아임웹 코드 위젯에 붙여 넣은 원본 HTML (01~14번) |
| `site/policy/privacy.txt` | 아임웹 설정 > 약관에 넣은 개인정보처리방침 원문 |
| `scripts/site_check.py` | 사이트 자동 점검 스크립트 |
| `.github/workflows/site-check.yml` | 매일 자동 점검 일정 |

## 사진·영상 주소 쓰는 법

주소는 항상 **커밋 번호를 고정**해서 씁니다. `@main`은 업로드 직후 404가 나거나 예전 파일이 보일 수 있습니다.

```
https://cdn.jsdelivr.net/gh/garpull0120/cheonun@<커밋번호>/파일이름
```

지금 홈페이지는 `7f6e5ccea7bcf5a5580ac49e0f22fb6c3fa2f2e0` 커밋의 파일을 쓰고 있습니다.
파일을 바꾸거나 지워도 이미 올라간 커밋 주소는 그대로 살아 있어서 홈페이지가 깨지지 않습니다.

## 매일 자동 점검

매일 오전 9시쯤 깃허브가 아래를 검사하고, 문제가 있으면 **이슈를 만들어 메일로 알려줍니다.**

1. 6개 페이지가 정상으로 열리는지
2. 하단 사업자 주소를 뺀 본문에 지역명이 없는지
3. 구글·네이버 소유확인 코드가 남아 있는지
4. 사이트맵에 우리 페이지만 있는지
5. 사진·영상 주소가 살아 있는지

매주 월요일에는 구글 Lighthouse로 속도·SEO 점수도 측정합니다 (Actions 탭 → 실행 기록에서 확인).
